# Singapore Red Cross 360° Feedback Playbook

An interactive web-based playbook developed in collaboration with **Singapore Red Cross** to support the implementation of a sustainable and psychologically safe **360-degree feedback** culture.

---

## 📖 Overview

The Singapore Red Cross 360° Feedback Playbook is an interactive learning platform designed to help employees, people managers, and HR professionals prepare for and navigate 360-degree feedback conversations effectively.

Unlike traditional performance reviews, the playbook focuses on creating a positive feedback culture by combining evidence-based HR practices with immersive, interactive learning experiences. Through scenario-based simulations, gamified activities, and practical tools, users develop the confidence and skills needed to give, receive, and act on feedback constructively.

This project was developed as part of an industry collaboration between **Ngee Ann Polytechnic** and **Singapore Red Cross**.

### 📖 Learning Modules

The playbook is organised around the **CARE Framework**.

| Module | Description |
|---------|-------------|
| **Clarify** | Learn how to prepare for feedback through proper documentation, expectation setting and evidence gathering. |
| **Address** | Practise giving constructive feedback while maintaining psychological safety. |
| **Respond** | Transform feedback into actionable improvement plans using SMART goals and guided reflection. |
| **Enhance** | Reinforce continuous improvement through follow-ups, recognition and progress tracking. |

## 🎯 Learning Scenarios

The playbook contains interactive scenarios designed to simulate real workplace feedback situations.

| Scenario | Learning Outcome |
|----------|------------------|
| Documenting employee performance | Teaches managers how to document employee performance accurately |
| Handling diffcult feedback conversations | Teaches managers how to conduct constructive and psychologically safe feedback conversations using the CARE framework |
| Turning feedback into action | Teaches people managers how to turn feedback conversations into actionable improvement plans and continuous follow-up using the CARE Framework |
| Receiving constructive feedback | Teaches employees how to receive feedback constructively without reacting defensively or emotionally |
| Speaking up and growing through feedback | Teaches employees how to provide respectful feedback, seek feedback proactively, and apply feedback for continuous improvement |
| Giving positive feedback | Encourages users to provide meaningful, evidence-based positive feedback through specific observations and recognition. |

## ❤️ CARE Framework

The playbook is built around the **CARE Framework**, developed specifically for Singapore Red Cross to guide constructive and psychologically safe feedback conversations.

| Stage | Purpose |
|--------|---------|
| **C — Clarify** | Gather facts, clarify expectations and prepare for the conversation. |
| **A — Address** | Deliver respectful, behaviour-focused feedback through two-way dialogue. |
| **R — Respond** | Translate feedback into actionable improvement plans. |
| **E — Enhance** | Reinforce positive behaviours through continuous learning and follow-up. |

The CARE Framework forms the backbone of the learning journey and is integrated throughout the playbook.
